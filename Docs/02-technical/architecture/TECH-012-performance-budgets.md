# Performance Budgets

Target platform is Windows. Exact min/recommended hardware and frame-rate target are `TBD`.

Before vertical slice completion define budgets for:

- Target FPS/frame time.
- Active projectiles.
- Niagara systems/overdraw.
- Skeletal characters.
- Audio/MetaSound CPU.
- Streaming/memory.
- Blueprint tick cost.

No system may claim a performance budget without profiling evidence.
