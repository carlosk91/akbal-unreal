# Editor Tooling and Content Validation

Add an `AkbalEditor` module only when repeated authoring needs justify it.

Candidate tools:

- Validate Data Asset IDs/references.
- Validate song sections/chart coverage.
- Validate attack timelines against musical boundaries.
- Validate naming/folder rules.
- Preview zone stem restoration.
- Report missing instrument/channel requirements.

Tooling must stay editor-only and must not add Editor dependencies to shipping runtime code.
