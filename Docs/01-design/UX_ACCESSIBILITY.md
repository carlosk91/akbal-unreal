# UX and Accessibility

## Known UX constraints

- Three primary bars only: Health, Shamanic Charge, Sync.
- Stun and ritual cooldown should be readable diegetically through patterns.
- Hidden heartbeat probability should not be exposed by default.
- Missing instrument gates must communicate capability, not input failure.

## Accessibility questions to resolve

- Non-color cues for pattern states.
- Rhythm calibration / audio-video offset.
- Timing-window accessibility without undermining progression.
- Bullet-hell readability and reduced-effects options.
- Remapping/controller support.
- Pause restrictions on Berserk path and accessibility implications.
