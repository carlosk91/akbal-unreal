# Visual Feedback and Body Patterns

## Goal

Communicate important state diegetically while retaining only three primary HUD bars.

## Alebrije pattern

Before ritual, pattern progression communicates prepared stun counters/potential.

During stun, pattern behavior communicates approximate remaining stun condition. Candidate visual dimensions for prototype:

- Coverage.
- Emission intensity.
- Segment fade.
- Pulse frequency.
- Desaturation.

Exact heartbeat probability remains hidden.

## Player pattern

Permanent pattern coverage increases as the player acquires power-ups/progression.

State presentation:

- Ritual available: emissive.
- Ritual active: emissive/animated.
- Ritual cooldown: opaque/dormant.

## Separation of visual channels

Permanent coverage communicates growth; emission communicates availability/state. Do not make one visual parameter encode unrelated values simultaneously.

## Prototype requirement

Art/UI prototype must test whether players can distinguish:

1. Stun buildup.
2. Approximate stun decay.
3. Ritual availability.
4. Ritual cooldown.
5. Permanent player growth.
