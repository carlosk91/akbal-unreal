# AI Prompt Library

These prompts are templates, not magic strings. Keep one agent role and one objective per task. Attach/reference the governing specs rather than pasting the entire repository into every prompt.

Recommended sequence for a new feature:

1. `PROMPT-001-spec-author.md`
2. Human approves behavior.
3. `PROMPT-003-technical-planner.md`
4. Human approves architecture.
5. `PROMPT-004-feature-implementer.md`
6. `PROMPT-005-test-engineer.md`
7. `PROMPT-007-code-reviewer.md`
8. `PROMPT-009-documentation-sync.md`
