# Akbal Feature Implementation Workflow

1. Read spec/plan/tasks/test plan and AGENTS.
2. Inspect existing patterns.
3. Implement tasks in dependency order with narrow diffs.
4. Add deterministic tests for rules/math.
5. Build/run targeted tests.
6. Update task status and report unvalidated items.
7. Do not change behavior outside approved spec.
