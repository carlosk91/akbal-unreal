# Akbal Feature Spec Workflow

1. Read `AGENTS.md`, governance, GDD and relevant SYS docs.
2. Inspect current code/docs for existing behavior.
3. Create/copy `Docs/04-features/_template`.
4. Write player-facing behavior, requirements, invariants, scenarios, edge cases and acceptance criteria.
5. Flag conflicts/TBDs; do not implement.
6. Ask for approval before moving to technical planning.
